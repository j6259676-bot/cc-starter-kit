# Feedback 範例檔 — 被糾正時這樣記

> 這是格式範例。真實的 feedback 檔照這個結構寫，檔名 `feedback_主題.md`，寫完在 MEMORY.md 加一行索引。

## 格式

```markdown
# 主題（一句話）

- **錯誤做法**：我當時做了什麼
- **正確做法**：應該怎麼做
- **原因**：為什麼（理解原因才能舉一反三，不只是背規則）
- **日期**：YYYY-MM-DD
```

## 真實範例

# 給小組長的訊息不用「親愛的」開頭

- **錯誤做法**：Email 草稿開頭寫「親愛的小組長們」
- **正確做法**：直接稱呼「各位小組長」或個人名字
- **原因**：「親愛的」在台灣教會語境顯得生疏又客套，主人的風格是直接、溫暖
- **日期**：2026-07-07
