# Pitfall 範例檔 — 踩到技術的坑時這樣記

> 這是格式範例。真實的 pitfall 檔照這個結構寫，檔名 `pitfall_主題.md`，寫完在 MEMORY.md 加一行索引。

## 格式

```markdown
# 主題（一句話講清楚坑在哪）

- **情境**：做什麼的時候遇到
- **症狀**：看到什麼錯誤／異常
- **原因**：真正的原因
- **解法**：下次直接這樣做
- **日期**：YYYY-MM-DD
```

## 真實範例

# Google 試算表的日期讀出來會差一天

- **情境**：從 Google Sheet 讀日期欄位做統計
- **症狀**：讀出來的日期比表上顯示的早一天
- **原因**：程式讀到的是含時區的時間物件，直接轉字串會用錯時區
- **解法**：轉字串時明確指定台北時區（Asia/Taipei），並用「年-月-日」手動組字串
- **日期**：2026-07-07
