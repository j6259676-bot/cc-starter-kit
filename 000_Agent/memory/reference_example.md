# Reference 範例檔

> 檔名 `reference_主題.md`。只記「在哪裡、怎麼找」，不要把內容整份抄進來 — 內容會變，位置比較穩。

```markdown
---
name: semester-plan-sheet
description: 本學期教學進度表在哪
metadata:
  type: reference
---

- **是什麼**：三年級本學期的教學進度表
- **在哪**：Google 雲端硬碟「教學／115 上」資料夾裡的「進度表」試算表（工作帳號）
- **什麼時候用**：排週計畫、寫聯絡簿提醒前先看這份
```
