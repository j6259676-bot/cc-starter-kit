給第一次用 AI 的人

30 分鐘，建立一個記得你的 AI 助理。

不是再開一個聊天視窗，而是一個記得你是誰、你在做什麼、你糾正過它什麼的工作夥伴。 你用得越久，它越懂你 —— 前提是你知道怎麼跟它磨合。這份起步包就是在教這件事。

三步驟開始 前往 GitHub

老師、行政、接案者、教會同事都適用。不需要會寫程式，不用開終端機，全程用中文對話完成。

你會得到什麼

三件事，一次設定完

這包東西本身只是一組文字檔，沒有魔法。真正的價值是它幫你把「AI 該記得什麼」變成看得見、改得動的檔案。

一個認識你的助理

它知道你的名字、工作、說話習慣，也知道哪些事要先問你、哪些可以直接做。每次開新對話都不用重講一遍。

一套看得見的記憶

你糾正過的錯、確認過的做法、進行中的事、東西放在哪，全部寫成檔案。你隨時可以打開檢查它記了什麼。

一套會自己長大的機制

同樣的錯犯兩次，它主動提案升級成規則；同樣的事做三次，它主動提案變成固定流程。你不用懂設定檔。

最重要的一課

它不是搜尋引擎，是新同事

想像今天來了一位很聰明、但完全不認識你的新同事。你不會期待他第一天就懂你， 你會在他做錯的時候告訴他。差別只在於：它的「記住」不是靠腦袋，是靠檔案。 檔案裡沒寫的，它下次就忘了。 所以關鍵動作只有一個：發現它做錯 → 當場糾正 → 確認它寫進了記憶。

「記下來」

任何它該永遠記住的事：「記下來：寫給家長的訊息，開頭不要用『親愛的』。」
追問「你記在哪個檔案？」就能點開確認。

「你為什麼這樣做？」

它的行為讓你意外時，先問原因，不要只是重來。它看得到自己的設定，通常能指出哪條規則太模糊，接著說「那幫我改掉」就好。

「要不要建成固定流程？」

同一類事情做到第三次（聯絡簿、學習單、會議紀錄），就叫它把步驟包成固定流程，以後一句話跑完。

默默自己改掉它的產出，是最浪費的做法 —— 你改了一百次，它還是不知道。 完整說明在 GROWTH.md， 設定完那天請讀一次。

它怎麼長大

糾正一次是記憶，兩次是規則，三次是流程

這套機制寫在它的核心規則裡，觸發時它會主動提，你只要點頭。

發生什麼事它會怎麼做結果存在哪
你糾正它一次寫下「錯誤做法 → 正確做法 → 原因」一個記憶檔，下次開工自動讀到
同一個錯犯第二次提案把它升級成絕對規則，你確認才改核心規則最上面，優先級最高
同一類事做第三次問你要不要建成固定流程一個流程檔，以後一句話跑完
規則寫了還是一直犯告訴你「記憶擋不住」，提案做成自動檢查每次動作前自動把關，不靠記性

怎麼驗收它，才不會被「應該可以了」騙

它說「改好了」的時候，你只要追問一句：

你的證據是什麼？
  • 合格：「我打開檔案確認了，你說的三點我逐條對過，第二段已經改掉。」
  • 不合格：「我已經改了，應該可以了。」—— 「應該」兩個字出現就要警覺
  • 它卡住的時候：同一件事失敗兩次就該停下來報告，不該一直試第三次、第四次

不裝也完全可以

核心就夠日常使用。設定時它會依你的工作推薦，也可以之後說「幫我安裝 modules/某某模組」。

一整學期的教材、一個報名頁、一個查資料的小工具 —— 講一句話講不完、做錯要重來的事。五個關口，每關你點頭才往下，不限程式開發。

卡住了？

先問它本人

九成的問題 —— 語氣不對、格式不對、它自作主張、你想加新功能 —— 它自己就能解決。 因為它看得到自己的設定檔，你只要說：

我想要 X，但你剛剛做成 Y，為什麼？我該怎麼調整設定？

真正需要問人的只有兩種：帳號與權限（安裝、登入、付費方案）， 還有「其他人都怎麼用」的經驗交流。
