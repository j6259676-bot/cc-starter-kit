# CLAUDE-snippet — design-media 模組規則

> 安裝時把以下內容合併進使用者的 CLAUDE.md（規則加進 §1，流程可以新開一段「## 設計與文案」）。

## 加進 §1 絕對規則

- **NEVER** The Hope 相關產出使用 emoji → 需要圖示用 Lucide Icons（stroke-width: 2）
- **NEVER** 品牌口號寫成 "THEY BELONG HERE" → 是 "YOU BELONG HERE"
- **ALWAYS** The Hope 介面與圖卡用官方色票（主色 `#1D292E` 深藍 / `#FFCC32` 黃），完整色票見 `modules/design-media/DESIGN.md`

## 新段落：設計與文案

- 做任何 The Hope 視覺產出前，先讀 `modules/design-media/DESIGN.md`（若 `200_Reference/design/` 有完整版則讀完整版）
- 寫對外文案前，先讀 `200_Reference/writing-samples/` 學語氣
- 對外文案完成後自動掃一次用語地雷：「同工」「物養」「THEY BELONG HERE」
- 交付網頁或圖卡時，同時給出使用的色票與字體清單，方便其他夥伴接手
