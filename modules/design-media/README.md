# design-media — 設計／媒體模組

給負責設計、媒體、社群、文宣的夥伴。**需要先裝 [the-hope](../the-hope/) 模組。** 裝完你會有：

1. **The Hope 設計系統**：AI 做任何介面、網頁、圖卡時自動套用官方色票、字體、圖示規則
2. **對外文案守則**：品牌用語（YOU BELONG HERE、服事夥伴）與語氣規範
3. **禁 emoji 守門**：The Hope 對外產出一律不用 emoji，改用 Lucide Icons

## 安裝步驟（Claude 照做）

### 1. 合併規則

把 [CLAUDE-snippet.md](CLAUDE-snippet.md) 的內容加進使用者 CLAUDE.md（先給使用者看過再改）。

### 2. 確認設計參考檔就位

[DESIGN.md](DESIGN.md) 是精簡版設計系統（色票、字體、常用配色組合）。完整版設計系統與 Logo 檔案請向線上分部 James 索取，取得後放 `200_Reference/design/`。

### 3. 帶跑一次流程

請使用者提供一個真實需求（活動宣傳卡、簡單網頁、社群貼文），做一次完整產出，示範 AI 如何自動套用色票與用語規則。做完問：「語氣和視覺有哪裡不像 The Hope？」把糾正寫進記憶。

## 日常用法

- 「幫我做一張某活動的宣傳圖卡（網頁版）」 → 自動套用官方色票與字體
- 「寫一則某活動的 IG 貼文」 → 遵循品牌語氣，先讀 writing-samples
- 「檢查這段文案有沒有違反品牌用語」 → 掃「同工」「THEY BELONG HERE」等地雷

## 為什麼有這些規則（背景）

這些不是美學偏好，是踩過的坑：

- 「同工」對圈外人是陌生術語，「服事夥伴」才傳達邀請與同行
- 口號是 **YOU** BELONG HERE — 對「你」說話的邀請；寫成 THEY 就變成在講別人
- emoji 在正式對外產出顯得廉價，且各平台渲染不一致；Lucide Icons 風格統一
