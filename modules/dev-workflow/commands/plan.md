把規格（或當前對話的共識）拆成**垂直切片**。

「垂直」的意思：每一片都從頭穿到尾（資料、邏輯、畫面），做完就有一個能動的東西。**不是**先把所有資料處理做完、再做所有畫面 — 那叫水平切，切完到最後一刻才知道對不對。

## 切片規則

1. **每片穿過所有層** — 哪怕功能只有一點點，也要是完整可跑的一條路
2. **每片完成後單獨可以拿給我看**：我打得開、看得到的東西（線上網址、一個畫面、一個輸出的檔案）。做不到這點的片，代表切錯了
3. **每片的大小** ≈ 一次對話能做完。做到一半要換新對話的片太大了，再切
4. **標明每片被誰擋住**（blocked-by）。沒被擋住的可以先做，也可以平行做
5. **例外**：純機械式的大範圍改動（全部改名、換網址、批次替換）不要硬切成垂直片。走「新舊並存 → 批次遷移 → 刪掉舊的」三段

## 輸出格式

編號清單，每片列三件事：

```
### 第 1 片：報名表單能收到一筆資料
- blocked-by：無
- 做完你會看到：填一次測試表單，Sheet 出現那一列
```

給我之後問我三個問題：**切太粗還是太細？順序對嗎？有沒有哪片其實不用做？**

我同意後存成 `100_Todo/projects/<專案名>/plan.md`。

## 節奏鐵則

**一片做完 → 給我看，附完成證據 → 我點頭 → 才做下一片。**

不要因為「反正下一片很簡單」就順手做完。也不要因為我說「不錯」就當作全部通過 — 我說的是這一片不錯。
