# pastoral — 牧養／小組模組

給負責牧養、小組、關懷事工的夥伴。裝完你會有：

1. **Notion 連接**：任務、名單、紀錄都能讓 AI 直接讀寫
2. **1on1 紀錄流程**：每次關懷談話後口述重點，AI 整理歸檔，下次談話前自動提醒上次脈絡
3. **會議紀錄整理**：貼上逐字稿或重點，產出結構化紀錄與待辦
4. **群發信踩坑精選**（[EMAIL-PITFALLS.md](EMAIL-PITFALLS.md)）：寄活動邀請、開課通知給幾百人時，怎麼不被 Google 退信

## 安裝步驟（Claude 照做）

### 1. 連接 Notion（若使用者有用 Notion）

在終端機執行：

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

然後重啟 Claude Code，第一次使用 Notion 工具時會跳出瀏覽器授權。
若使用者不用 Notion，跳過此步 — 紀錄改存本機 `100_Todo/projects/pastoral/`，流程相同。

### 2. 合併規則

把 [CLAUDE-snippet.md](CLAUDE-snippet.md) 的內容加進使用者 CLAUDE.md 的適當段落（先給使用者看過再改）。

### 3. 建立 1on1 紀錄結構

問使用者：「你固定關懷／1on1 的對象大概有哪些人？」然後建立：

- Notion 使用者：一個「關懷對象」資料庫（欄位：姓名、近況、上次談話日期、代禱事項）+ 一個「談話紀錄」資料庫（欄位：對象、日期、重點、後續行動）
- 本機使用者：`100_Todo/projects/pastoral/人名.md`，每人一檔，新紀錄往上加

### 4. 帶跑一次流程

請使用者回想最近一次關懷談話，口述 2-3 句重點，示範完整流程：整理 → 歸檔 → 下次如何調出脈絡（「我明天要跟某某碰面，幫我準備」）。

## 日常用法

- 「我剛跟某某聊完，重點是……」 → 整理歸檔
- 「明天要跟某某 1on1，幫我準備」 → 調出上次紀錄、未完成的關懷事項、代禱事項
- 「這是今天小組長會議的逐字稿，整理一下」 → 結構化紀錄 + 待辦清單
- 「這個月我關懷過誰？誰太久沒聯絡了？」 → 掃描紀錄回報

## 個資提醒

關懷紀錄是敏感個資。原則：只存在 Notion（教會工作區）或本機，AI 不得把成員全名+聯絡方式+關懷內容貼到任何其他對外服務。這條規則已包含在 CLAUDE-snippet 裡。
